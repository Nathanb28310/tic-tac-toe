# tic-toc-toe

Ce projet m'a été proposé pendant ma première année au sein de Coda, sur le module de la programmation bas niveau.
Ce projet reprend le principe du morpion.

Voici les conditions qui m'ont été imposées : 

- Être en langage C.
- Le jeu compile sans erreur ni warning
- Le jeu affiche le plateau de jeu vide
- Le jeu demande au joueur en quelle position jouer
- Si le joueur essaie de tricher, il ne peut pas
- Le jeu place le symbole du joueur à la bonne case
- Le jeu place ensuite le symbole de l'ordinateur
- On peut gagner en ligne, colonne, ou diagonale
- Le joueur peut gagner
- L'ordinateur peut gagner
- La partie peut être nulle
